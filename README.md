EMBERLINE — a solo tactical FPS in a dusk container yard. You are the EMBER operative: plant the charge at site A or B and defend it until detonation, or eliminate the three CINDER defenders. Round-based with an economy and buy menu (SMG, rifle, grenades, Kevlar), bot AI that holds lanes, rotates and defuses, and synthesised WebAudio sound. First to 3 round wins takes the match.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click to start (pointer lock), WASD to move, mouse to aim, click to fire, E to plant, B to buy, R to reload, G for a grenade.
